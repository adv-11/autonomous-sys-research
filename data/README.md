# Local datasets

Datasets are not committed. Follow applicable access processes and terms. Record release versions, checksums, split manifests, annotation policies and image-group identifiers before use.

All seven official ACDC archives match publisher MD5 values, have recorded SHA-256 hashes, pass ZIP CRC checks and are extracted locally. Images are under `acdc/extracted/rgb_anon_trainvaltest/rgb_anon/`; annotations are under their separate archive directories in `acdc/extracted/`.

BDD100K acquisition/release verification continues: a complete image mirror archive matches its mirror hash but not the publisher's archive MD5. See [the acquisition record](../docs/data_acquisition.md) and [ACDC archive manifest](../docs/datasets/acdc_archive_manifest.json) for evidence and limitations. Nothing in this directory except this README is tracked by Git.
