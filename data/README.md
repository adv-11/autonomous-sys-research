# Local datasets

Datasets are not committed. Follow applicable access processes and terms. Record release versions, checksums, split manifests, annotation policies and image-group identifiers before use.

Acquisition is now in progress: six official ACDC annotation archives are verified and extracted locally; ACDC images are still transferring. A completed BDD100K mirror archive matches its mirror hash but not the publisher's archive MD5, so its dataset identity remains unverified. See [the acquisition record](../docs/data_acquisition.md) for evidence, paths and limitations. Nothing in this directory except this README is tracked by Git.
