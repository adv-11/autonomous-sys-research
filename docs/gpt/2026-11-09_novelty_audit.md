## Conditional finite-pool selection completeness

**GPT derivation; supporting elementary result, not a PhD novelty claim.** Fix an image, checkpoint, head, preprocessing, score representation and finite pool `P` of stable labelled candidate identities. Let acquisition produce `C⊆P` through a fully inventoried sequence of deletion-only stages that do not change scores/labels/geometry. For each stage's removed set `D_j`, provide a valid upper bound `b_j` on its original scores and whether that bound is inclusive. Bounds must concern the evaluation population or a conservative all-class superset. A stage with no removals needs no bound.

With final inclusive threshold `s≥t`, if every omitted candidate is strictly below `t`, then

`{d∈C:s_d≥t} = {d∈P:s_d≥t}`.

Proof: membership in the left set implies membership in the right since `C⊆P`. An element in the right but not left belongs to a removed set, contradicting its score bound. A usable sufficient condition is `t>b_j` for inclusive bounds, or `t≥b_j` for strict bounds, for **every** stage. A failed sufficient test means **UNKNOWN**, not demonstrated incompleteness. An actual omitted in-scope candidate with score `≥t` witnesses incompleteness. Unknown stage inventories, timeouts, missing coverage or changed pool identity invalidate the certificate. No label, TP, matching or environmental assumption enters this statement.

| Operator / counterexample | Required assumption and consequence |
|---|---|
| **Strict floor** `s>f` | Removed scores satisfy `s≤f`; inclusive final threshold requires `t>f`. With one item `s=f=t=.5`, acquisition drops a final-threshold item. For acquisition `s≥f`, removed scores are `<f`, so `t=f` is safe for that stage. |
| **Top-k ties** | Omitted scores are `≤` the kth kept score `b`, so `t>b` is safe. Scores `.8,.8`, k=1, t=.8 lose one ID. Equality needs a verified strict omitted bound or all boundary ties retained; arbitrary new tie IDs cannot supply it. With zero cap and a nonempty pool, a kth score does not exist. |
| **All-class vs class-first** | Car .9/person .8, k=1 yields no person globally and one with person-first selection. A global omission bound can conservatively certify the person subset, but filtering the final cache cannot reproduce class-first acquisition. Argmax-before-filter differs again from ranking each class score. |
| **Hidden head top-k** | An API cap 3000 cannot recover a head returning only its first 300. Record each stage. YOLO26 selects anchors by class maximum then pairs; if both budgets equal k, omitted-anchor pairs cannot outrank k retained anchor maxima, giving global top-k **score-value** equivalence. Native identities at ties need separate evidence. With preliminary h<final k, retain a separate discarded-anchor maximum bound. |
| **Hard NMS** | NMS can suppress B=.9 behind overlapping A=.95 while final kth kept C=.1. Thus `.1<t=.8` cannot certify completeness relative to the pre-NMS pool. Name a post-NMS reference pool or account for suppression separately. For fixed deterministic score/ID order, boxes, classes and IoU, greedy hard NMS is prefix-consistent: decisions on scores≥t depend only on earlier candidates. This permits some floor/cap replay relative to the **same full NMS policy**, not equality to unsuppressed predictions. |
| **Timeouts / dynamic pools** | Unprocessed frames can lose arbitrarily high scores; output count below cap gives no bound. New tiles/queries, a head switch, precision or preprocessing change creates a different pool; a certificate for P says nothing about added high-score item Q. Freeze and bind image/pool identity, execution completion and every stage. |
| **Float / rounding / score changes** | `.50004` and `.50003` both round to `.500`; thresholds and ties can change. Sigmoid saturation can collapse distinct logits. Use actual dtype/full precision and comparisons, with no arbitrary epsilon. Quantized interval bounds require lower(t)>upper(omitted), or exact endpoint reasoning. Soft-NMS, learned NMS and box fusion fall outside the unchanged-score/deletion assumptions. |

Minimum evidence: hashes/versions for image, checkpoint, head, preprocessing and policy; input-pool definition; primitive anchor/query+class IDs before selection; score dtype and unrounded values; class-expansion/filter order; realized head k/max_nms/final cap; floor comparator; omitted-score bounds and tie inclusion per stage; geometry transformation; execution/time-limit and unknown flags. Returned-row IDs are insufficient for cross-policy identity checks. Even full metadata is a **conditional** certificate: adapter correctness still needs validation.

The [existing monotone-reselection theorem](protocol.md#5-monotone-recalibration-theorem-and-exceptions) remains the relevant calibration control. Transforming every score, bound and observed boundary with one strict global map preserves comparisons and completeness. Applying a new fixed numeric prefilter, pooling classwise maps, changing ranks/ties or rounding violates its assumptions. A complete selection may have recall zero; an incomplete selection may retain all true objects. No recall/calibration benefit follows from the certificate.

An additional algebraic caution: one TP ranked behind 999 FPs can give AP around .001 yet all-candidate recall one. Consequently low AP alone does not identify whether GT are absent from a finite candidate pool. Measuring a ceiling adds a diagnostic; calling that diagnostic a new theory would overstate it.
