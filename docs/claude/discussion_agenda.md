# Questions to resolve in the GPT–Claude discussion

**Coordinator agenda, 2026-11-03.** These are questions about the initial Claude audit, not a completed exchange or an approval. The initial Claude contribution is commit `4af4f810f36851b462298a9b473dd421f30e6ba3`; it is preserved separately from this agenda. My research PRs should wait for the actual exchange and revisions.

1. **Monotone calibration and candidate selection.** O3 correctly establishes invariance for one strictly increasing scalar transform with a correspondingly selected threshold and deterministic tie handling. Does its list of exceptions need tightening? Applying the same transform before score-ranked top-k or conventional score-ranked NMS also preserves ordering. A change requires an additional mechanism: class-specific maps, changed cross-class rankings, fixed numerical cutoffs, score-weighted box operations, or a condition-dependent transform. Merely moving the same map earlier is insufficient.
2. **Signed loss versus positive shortfall.** In O4, `U_c = max(0, R* - R_max,c)` and `T_c = min(R*, R_max,c) - R_c(τ*)` sum to the signed gap `R* - R_c(τ*)`, but `T_c` becomes negative if target recall is exceeded. Should the main report use the nonnegative shortfall `max(0, R* - R_c)` and threshold component `max(0, min(R*, R_max,c) - R_c)`, while retaining the signed gap as a separate descriptive quantity? The decomposition must be explicit about this distinction.
3. **Feasibility versus a safety margin.** `R_max < R* + 0.02` is a proposed acceptance margin, not mathematical infeasibility. A model with `R_max = 0.91` can reach a target of 0.90. Distinguish an unattainable target (`R_max < R*`) from insufficient headroom or an uncertainty-based feasibility criterion. Freeze the decision rule before examining model comparisons.
4. **Independent data roles.** The Claude diagram combines calibrator fitting and threshold selection in one clear-day calibration half. Should the protocol instead reserve disjoint calibrator-fit, operating-point selection, and held-out evaluation groups, with sequence grouping and reproducible manifests? State when cross-fitting is acceptable and how uncertainty includes threshold selection.
5. **Architecture evidence.** The YOLO26 dual-head contrast reduces backbone and recipe confounding but still combines differences in learned head weights, assignment, candidate count, and postprocessing. Verify both branches exist in the pinned released checkpoint and record explicit settings. Describe a head/pipeline contrast rather than claim the isolated causal effect of NMS or assignment.
6. **Dataset and annotation scope.** Confirm whether annotations actually allow matched ACDC reference/adverse comparisons, and match the comparison population rather than treating route correspondence as exact object pairing. Keep ignore-region thresholds and class-policy choices provisional until the annotation files are inspected.
7. **Evidence precision.** Record full hashes if using checksums for reproducibility; the initial audit currently records abbreviated hashes. Qualify claims that a paper has no code as “no code link found in the inspected sources” unless an exhaustive release search was done. Source verification and exact replication are separate claims.
