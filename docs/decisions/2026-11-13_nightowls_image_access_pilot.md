# Proposed bounded NightOwls image-access pilot

I initially authorized validation annotations only. I subsequently explicitly authorized **this bounded image-access pilot** on 2026-11-13; the licence is accepted. The quantitative external study and GPU work remain unauthorized by this step. GPT Sol fixed the private selection before any image/index retrieval, using only native night image IDs and recording metadata, never GT counts or model outputs. The [configuration](../../configs/research/nightowls_image_access_pilot_20261113.json) pins the annotation and private-manifest hashes.

Select ten hash-ranked night frames from each of the five known recording keys and fourteen from the unkeyed bucket: **64 images maximum**. The unknown bucket is not treated as one sequence. Keep the selection fixed even if it contains empty frames or proves inconvenient to retrieve. All 64 planned pilot paths are excluded, regardless of retrieval success, from a later quantitative image pool; no detector outputs, threshold choice or method fitting occur in this development/access pilot.

The authorized transfer cap is **150 MB of HTTP response bodies**, including at most 16 MB of private ZIP-index metadata, with a **30-minute wall limit**. The complete archive is approximately 57.5 GB and is not an allowed fallback. For every archive GET, require HTTPS, status 206 and a Content-Range matching the requested bytes; otherwise stop before reading its body. Every partial response must report the same total size. Pin ETag/Last-Modified when supplied and stop if a value changes. All body bytes read, including failed reads, count toward the cap. Preserve original selected PNGs privately; decode them and compare native dimensions to the annotations. Stop at the first transport/identity/CRC/decode failure or cap, retain partial evidence, and do not replace images or enter a repair loop.

This phase uses local CPU and **zero Colab sessions or GPU operations**. It addresses the concrete transport bottleneck that prevented the previous expanded ACDC run. Selective retrieval and throughput are unverified, and completing all 64 images is not guaranteed within the cap. No new package, generic streaming framework, full-archive download, redistribution or quantitative research result is part of this authorization. A successful access pilot would support a separate, concrete acquisition/inference proposal; it would not pass G0.

Selection is ascending `(SHA256(UTF-8(seed + ":" + str(native integer image ID))).hexdigest(), native integer image ID)` within each recording bucket, using the configured seed; ties use ascending native image ID. The private selection hash is unchanged. PNGs, logs and archive-index metadata will be stored only under the gitignored `data/nightowls/image_access_pilot/2026-11-13/` tree, in its `images/`, `logs/` and `archive_index/` subfolders.
